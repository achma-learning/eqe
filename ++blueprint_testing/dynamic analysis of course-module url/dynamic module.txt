### 1. The Scraping Logic (Dashboard)

To auto-detect the course URLs, you need a function that runs on the dashboard page (`/dashboard`). Use the class structure seen in your images (the `grid` container and the `a` tags) to map the titles to their unique UUIDs.

```javascript
// Run this on the dashboard to collect your "Loadouts"
const getCourseLoadouts = () => {
    const courseLinks = document.querySelectorAll('a[href*="/dashboard/course/"]');
    return Array.from(courseLinks).map(link => {
        const titleElement = link.querySelector('h3') || link.querySelector('span'); // Adjust based on exact text location
        return {
            name: titleElement ? titleElement.innerText.trim() : "Unknown Course",
            url: link.href,
            id: link.href.split('/').pop() // Extracts the UUID
        };
    });
};

// Save to persistent storage for use on lesson pages
GM_setValue('saved_courses', getCourseLoadouts());

```
