### 🛠️ Step 1: Automated Course Scraper

Add this function to run when you are on the `/dashboard` page. It targets the `grid` and `a` tags seen in your images to map course titles to their UUIDs.

```javascript
const scanAndSaveCourses = () => {
    const courseLinks = document.querySelectorAll('a[href*="/dashboard/course/"]');
    const courses = Array.from(courseLinks).map(link => {
        // Targets the <h4> tag within the anchor for the course name
        const nameElement = link.querySelector('h4'); 
        return {
            name: nameElement ? nameElement.innerText.trim() : "Unknown Module",
            url: link.href,
            [cite_start]id: link.href.split('/').pop() // Extracts the UUID [cite: 29]
        };
    });
    
    if (courses.length > 0) {
        GM_setValue('saved_courses', courses);
        showHUDToast("📚 Courses Scanned & Updated!");
    }
};

```

### 🛠️ Step 2: The "Module Loadout" UI logic

Since you want the same style as your timer loadouts, you should create a function that builds a semi-transparent grid overlay. Use the following logic to create the "Game Menu" feel:

```javascript
const showCourseSwitcher = () => {
    const courses = GM_getValue('saved_courses', []);
    if (courses.length === 0) return showHUDToast("❌ No courses found. Visit Dashboard first.");

    const overlay = document.createElement('div');
    overlay.className = 'game-menu-overlay'; // Use your existing blur/dark styles
    overlay.innerHTML = `
        <div class="menu-content">
            <h2>Select Module</h2>
            <div class="course-grid">
                ${courses.map((c, i) => `
                    <div class="course-card" onclick="window.location.href='${c.url}'">
                        <span class="key-hint">${i + 1}</span>
                        <p>${c.name}</p>
                    </div>
                `).join('')}
            </div>
            <p class="footer-hint">Press [Esc] to cancel</p>
        </div>
    `;
    document.body.appendChild(overlay);
};

```
