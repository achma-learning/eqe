# Keyboard Shortcuts:
1-5 or A-E - Select answer
Space/Enter - Check answer

Shift+A - Toggle Auto-Advance
Shift+S - Open Settings

Configurable answer timer (default 5s)
Auto-select random answer on timeout (optional)
Dynamic Island timer display
Persistent settings
